# 🔔 Digital Security Alarm Using Logic Gates

## 📌 Project Overview

A beginner-friendly Digital Electronics project that simulates a simple security alarm using basic logic gates.

The alarm activates when the security system is enabled and either the door or window sensor is active.

## 🎯 Objective

The objective of this project is to understand:

- Logic Gates
- Boolean Algebra
- Truth Tables
- Digital Inputs and Outputs
- Digital Circuit Design
- Circuit Simulation

## 🧠 Logic

The system has three inputs:

- D = Door
- W = Window
- E = Enable

And one output:

- A = Alarm

### Boolean Expression

```text
A = (D + W) · E
